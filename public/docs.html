Public Core

Evaluate operational stability before execution.

This public release includes the core evaluator and demo boundary only. Billing, API-key provisioning, customer console, private replay, and telemetry surfaces are intentionally excluded.

POST /api/evaluate

curl -X POST https://your-domain.example/api/evaluate \
  -H "Content-Type: application/json" \
  -d '{"packet_id":"demo-001","truth":{"claims":["state is verified"],"observations":["state is verified"]},"accountability":{"responsible_actor":"operator","authority_basis":"demo"}}'

Response boundary

The evaluator returns an operational decision such as allow, constrain, escalate, or block, plus a deterministic artifact hash. It does not expose private customer data, billing state, or deployment secrets.
