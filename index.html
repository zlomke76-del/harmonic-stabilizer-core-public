Harmonic v4.0.0 public contract

Govern continuation before consequence.

Harmonic is a constitutional continuation runtime that evaluates whether the conditions supporting a proposed action remain admissible immediately before consequence binds.

Read the V4 contractOpen reference demo
Public repository boundary: this repository publishes the architecture contract, SDK/reference surfaces, and selected frozen evidence. The included JavaScript evaluator is a public-safe demonstrator, not the sovereign production runtime.

Present state

Reality must be attributable now

Historical correctness does not automatically establish present admissibility. Harmonic evaluates the state supplied at the execution boundary and preserves epistemic limitations.

Authority

Authority must remain continuous

Identity and delegation do not guarantee that authority remains valid as institutional conditions change. Runtime continuation is evaluated against operative authority state.

Consequence

Determination is not execution

Harmonic can permit, constrain, escalate, refuse, or invoke emergency-continuity handling without claiming that the downstream executor actually acted.
